# Day 02 - Modern Java Syntax: Records, Sealed Classes, Pattern Matching

> **Phase:** Java Foundations | **Date:** 2026-03-02 | **Code:** [`ModernJavaSyntax.java`](./ModernJavaSyntax.java) | **Runtime:** JDK 21+

## 1. Core Concepts

### Records (Java 16)
A record is a *transparent, shallowly immutable data carrier*. The compiler generates the canonical constructor, accessors, `equals/hashCode/toString` (all via `ObjectMethods` bootstrap + `invokedynamic`, not generated bytecode). Use the **compact constructor** for validation and defensive copies. Records cannot extend classes, cannot declare instance fields, but can implement interfaces, have static members and nested types.

### Sealed types (Java 17)
`sealed interface Shape permits Circle, Square` restricts the hierarchy. Each permitted subtype must be `final`, `sealed` or `non-sealed`. The compiler then knows the closed set, which enables **exhaustive `switch` without `default`** - adding a new subtype breaks compilation at every switch, which is exactly what you want in domain modelling (algebraic data types / sum types).

### Pattern matching (Java 16-21)
* `instanceof` patterns: `if (o instanceof String s && s.length() > 3)`.
* `switch` patterns with guards: `case Success s when s.latency() > 100 -> ...` (final in 21).
* **Record deconstruction patterns**, nestable: `case Add(Const(var a), Const(var b)) -> new Const(a + b)`.
* Dominance: a more general label may not precede a more specific one (compile error).

### Other modern features worth knowing
`var` (10), text blocks (15), switch expressions with `yield` (14), `Stream.toList()` (16), **sequenced collections** (21: `getFirst()`, `getLast()`, `reversed()`), unnamed patterns `_` (22+), `String.formatted`, `Objects.requireNonNullElse`.

### Why it matters for AI backends
Inference outcomes are naturally a sum type: `Success | Failure | Timeout`. Sealed + records makes the compiler enforce that every caller handles every outcome. Feature-expression trees, query ASTs and DSL interpreters get the same benefit.
